# Forecasting Model Access

## Overview

This research investigates hybrid machine learning architectures for animal-level cattle live-weight forecasting in grazing-based production systems.

## Model Architectures

The investigated hybrid architecture families include:

1. Residual hybrid models.
2. Stacked hybrid models.
3. Cascade hybrid models.
4. Ensemble-assisted neural models.

Comparative baselines include persistence, LSTM, and GRU for animal-level forecasting. ARIMA is evaluated separately at the aggregated herd level.
