# Software Requirements

## Programming Environment

The manuscript reports the use of Python 3.11 for model development and evaluation.

## Main Libraries

The documented implementation uses:

- Scikit-learn
- TensorFlow
- XGBoost

Additional dependencies and exact package versions should be obtained from the final validated execution environment.

## Execution Requirements

Reproducing the research experiments requires:

1. Approved access to the relevant datasets.
2. The corresponding model implementation files.
3. Compatible Python and package versions.
4. Documented preprocessing and feature-engineering procedures.
5. The specified training, validation, and testing configuration.
6. Random seeds and model hyperparameters.
